```ts
export type GreetingCatalogue = {
  greeting: string;
  nameMissing: string;
  nameRejected: string;
};

export type GreetingOutcome =
  | { exitCode: 0; stdout: string; stderr: "" }
  | { exitCode: 1; stdout: ""; stderr: string };

export function greet(positional: readonly string[], catalogue: GreetingCatalogue): GreetingOutcome
```

`positional` is the argument list after the node binary and the script (`process.argv.slice(2)`). Apply the checks in this order (`docs/CONTENT_MODEL.md` "The name argument"):

- `positional.length !== 1` → refusal `nameMissing`. Do not inspect the arguments further.
- Otherwise `trimmed = positional[0].trim()` (`String.prototype.trim`). `trimmed.length === 0` → `nameMissing`.
- Otherwise `trimmed` starts with `-` (U+002D HYPHEN-MINUS) → `nameRejected`. `--help` is this refusal. There is no help text.
- Otherwise success. The printed name is `trimmed`. Internal spaces stay.

A success stdout is `catalogue.greeting.split("{name}").join(trimmed)` plus `\n`. Use that split and join so a `$` in the name is literal (`String.prototype.replace` would expand `$&`). A refusal stdout is `""` and its stderr is the matching catalogue sentence plus `\n`. Do not append the argument to a refusal. `greet` does not throw for a refusal, does not read `process.argv`, does not call the logger, and does not touch a file.
