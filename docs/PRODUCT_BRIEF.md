# Product brief — Hello CLI

**Code:** HELLO-CLI
**Name:** Hello CLI

Hello CLI is a command-line tool that prints a greeting for a name. The people who run it are
developers, on their own machines. It does not store the name, does not send it, and does not
sign anyone in.

The command is English only. It is not a website, not a service, and not a library that another
program is expected to embed. The git repository is public. Nothing is deployed.

The words of the greeting, the shape of the argument, and the refusals are `docs/CONTENT_MODEL.md`.
The MVP is that command and nothing else (`docs/SCOPE.md`, OD-02).
